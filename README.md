# Kababaa — App Downloads

Installable APK builds of the **Kababaa** app.

## Download

Grab the latest `.apk` from the **[Releases](../../releases/latest)** page.

- Download the file to your Android phone
- Open it and allow "Install from unknown sources" if prompted
- Open the app and sign in

> This repository contains **only** the built APK files — no source code.
